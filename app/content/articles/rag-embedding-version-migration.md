Embedding 把文本映射成向量。检索时问题向量和文档向量需要使用相容的模型与处理方式。即使新旧模型输出维度相同，数值也不代表同一个语义空间；只替换查询侧的模型，旧索引的距离分数就失去原来的含义。

安全的迁移方式是给片段记录模型版本、切块版本和文档版本，建立独立的新索引。先用固定问题集对照新旧索引的召回、引用和延迟，再逐步切换读流量。写入期间要明确新文档进哪个版本，不能让一次增量更新把两种向量混进同一个集合。

## 删除也需要版本意识

重建索引不是只追加新向量。原文被删除、权限被撤销、章节被修改时，旧片段也必须失效。否则检索可能引用已经不存在或不再授权的内容。

发布时保留一段可回滚窗口，观察真实查询中的空召回、重复引用和延迟变化；确定新索引稳定后再清理旧索引。模型升级是一项数据迁移，不只是一次 API 参数更新。
